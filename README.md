## ✨ Modules & Features

### 📊 Core Features
* **Dashboard:** Live statistics summary tracking total tickets, critical priority items, in-progress tasks, and resolution rates, along with a recent activity preview.
* **Ticket List & Management:** Comprehensive table view featuring search by subject/ID, and dropdown filters for ticket statuses and priorities[cite: 1, 3].
* **Create Ticket:** Interactive form interface to submit new support requests with categories, priorities, assignee selection, and detailed descriptions[cite: 1, 3].
* **Knowledge Base:** Built-in FAQ section providing quick answers and standard support documentation articles[cite: 1, 3].
* **Agent Management:** Support team directory detailing active agent workloads, roles, and availability status[cite: 1, 3].
* **Reports & Analytics:** Performance overview tracking average resolution times, customer satisfaction (CSAT) scores, and SLA compliance rates[cite: 3].

### 🎨 Design & Styling Guidelines
* **Color Palette:** Professional purple theme (`#7C3AED` primary purple, white elements, and light gray background)[cite: 2].
* **Typography & Vibe:** Clean, modern, corporate, and structured support-focused layout[cite: 2].
* **Responsiveness:** Fully responsive design adapting seamlessly to desktop, tablet, and mobile screen sizes[cite: 2].
